# 拼豆图纸工作台

单店主在浏览器里把顾客发来的图片做成拼豆网格、用豆清单、成本明细和建议零售价。计算都在本机完成，图片不会上传。

这一版不做客户账户、支付、订单，也不调用外部 AI。

## 本地运行

需要 Node.js 22 或更新版本。

```bash
npm install
npm run dev
```

开发服务器监听 `0.0.0.0:43127`。在运行这台机器的浏览器打开：

[拼豆图纸工作台](http://127.0.0.1:43127)

生产构建：

```bash
npm run build
npm run preview
```

`preview` 同样使用 43127 端口。

## 检查

```bash
npm run typecheck
npm test
npm run build
```

`npm test` 覆盖透明像素不计豆、颜色颗数与总豆数一致、网格尺寸和最大颜色数边界、损耗取整、毛利率与加价率、保底售价，以及 CSV 公式注入。

## 怎么用

1. 上传 PNG、JPEG 或 WebP（不超过 8MB），或载入「原创试用素材」。
2. 调整最长边格数、最大颜色数和透明判定。长边保持原图比例。
3. 查看网格坐标、色号、每色颗数和总豆数。
4. 填写每颗成本或分色单价、损耗、工时、时薪、包装和其他成本。
5. 看成本合计、建议售价，必要时手改最终报价。
6. 导出 PNG 图纸和用豆清单 CSV，或把方案保存到此浏览器。

大图会先把长边缩到 1200 像素，再按行计算，避免一次卡住页面。Alpha 小于或等于阈值的像素，以及不透明像素不足一半的格子，不计豆。

## 色板

默认「纸间」是本工具自编的示例色板。K1、R2 这类代号只为对照格子，**不对应** MARD、Perler、Hama、Artkal 或任何品牌的官方色号，也不能保证和实物颜色一致。

可以在「色板」里改成自己的代号、名称和 HEX。请不要把品牌官方色号填进来当作本工具的认证数据。

## 价格

默认 0.05 元/颗、8% 损耗、1 小时、25 元/小时、1.50 元包装、40% 毛利率，都是方便试算的**示例假设**，不是市场报价。

- 成本合计 = 豆材 + 人工 + 包装 + 其他
- 含损耗采购颗数 = 向上取整(用量 × (1 + 损耗率))，每种颜色分开算
- 人工 = 工时 × 时薪，四舍五入到分
- 按毛利率反推的售价 = 成本合计 ÷ (1 − 目标毛利率)
- 毛利率 = (售价 − 成本) ÷ 售价
- 加价率 = (售价 − 成本) ÷ 成本

毛利率不是加价率。成本 60 元、毛利率 40% 时，建议售价是 100 元，加价率约 66.67%，不是 84 元。

建议售价取「按毛利率反推」「成本 + 最低利润」「最低人工保底」里启用项的最大值。填 0 的保底不参与。建议售价只供店主参考，最终报价可以手改。金额算到分。目标毛利率必须大于等于 0% 且小于 100%。

## 数据存在哪里

方案、自编色板和记住的成本参数只写在**当前浏览器的 IndexedDB**（库名 `pindou-workshop`）。换浏览器、无痕窗口或清除站点数据后无法找回，不会同步，也不会上传。

保存的图片是用于出图的副本，长边不超过 1200 像素。原创示例不是客户单据。

导出的 CSV 使用 UTF-8 BOM。以 `=`、`+`、`-`、`@` 开头的单元格会加上单引号，避免表格软件把它当成公式。

## 临时预览和持久部署

`npm run dev` 只在当前这台机器上提供页面，进程停了就没有。它不是已经发布的网站，也没有独立域名。

若要长期给自己用，需要在你确认仓库名称和可见性之后，自行构建并把 `dist/` 放到你选择的静态托管。本仓库不代为购买托管、不配置付费服务，也不把顾客图片送到外部服务。
